# Amazon Sales Dashboard

This project is an Amazon sales dashboard that helps sellers analyze their sales data and track performance over time. It provides key insights into sales trends, product performance, revenue, and other key metrics, all displayed in an interactive dashboard format.

---

## 📁 Files Included

- **`amazon-sales-data.xlsx`** – Raw sales data exported from Amazon Seller Central.
- **`amazon-dashboard.pbix`** – Power BI report file for visualizing the sales data interactively.

---

## ⚙️ How to Use

1. **Open the Excel file** to review the raw sales data.
2. **Open the `.pbix` file in Power BI Desktop** to view and interact with the dashboard.
3. If the data source path is broken, you may need to update the file path in Power BI:
   - Click on **Transform Data** → **Data Source Settings** → **Change Source**.
4. Refresh the data to see the updated visualizations.

---

## 🧰 Tools Used

- **Excel** – Data storage and basic analysis.
- **Power BI** – Dashboard creation and data visualization.

---

## 🛡️ Notes

- All sensitive or personal information has been removed.
- This is a sample dashboard based on typical sales data.
- For real use, update the Excel file with your own Amazon data.
